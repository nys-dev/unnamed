# 날씨 데이터 출처

## Decisions

- 러닝 적합도 판단에 쓰는 날씨 데이터는 국내 공공 API 세 가지를 조합해 얻습니다. 풍속, 온도, 강수확률은 기상청 단기예보 조회서비스, 자외선 지수는 기상청 생활기상지수 조회서비스, 미세먼지는 한국환경공단 에어코리아 대기오염정보의 대기질 예보통보를 사용합니다.
- 조회 범위는 오늘, 내일, 모레입니다.
- 공휴일 여부는 한국천문연구원 특일 정보 API로 확인합니다. 고정 목록은 매년 갱신해야 하고 임시공휴일을 놓칠 수 있어 쓰지 않습니다.
- 미세먼지는 시도 단위의 하루 4등급(좋음, 보통, 나쁨, 매우나쁨) 예보로만 판단합니다. 시간대별 수치 기준은 쓰지 않습니다.
- 네 API는 공공데이터포털(data.go.kr)의 인증키로 호출합니다. 키는 저장소에 넣지 않습니다.

## Boundaries

- 지역은 기상청 동네예보 지점 좌표 파일(행정구역코드, 격자 X/Y, 위경도)로 찾고 변환합니다. 현재 위치는 가장 가까운 동 단위 지점을 씁니다.
- 시도 단위 미세먼지 등급은 같은 날 안에서 시간대를 구분하지 못합니다.

## Why

사용자는 정확도와 오늘, 내일, 모레의 예보를 요구했습니다. 기상청과 에어코리아는 국내 공식 관측과 예보를 제공하고, 세 값을 모두 같은 3일 범위로 얻을 수 있습니다. 단일 서비스는 요구한 값 중 일부가 한국 관측이 아닌 모델 값이거나 빠져 있었습니다.

## Reconsider when

- 세 API 중 하나가 폐지되거나 호출 조건(인증, 일일 한도)이 개인 사용에 맞지 않게 바뀔 때
- 시도 단위 미세먼지 등급이 판단에 너무 거칠다는 사용 기록이 쌓일 때
- Open-Meteo가 한국 모델 갱신을 재개하고 시간별 강수확률과 한국 관측 기반 대기질을 제공할 때

## Still-rejected alternatives

- Open-Meteo 단일 서비스 — 한국 모델(KMA) 갱신이 중단 상태이고, 시간별 강수확률이 없으며, 미세먼지와 자외선이 약 45km 해상도의 글로벌 모델 값입니다. 위 재검토 조건이 충족되면 다시 봅니다.

## Evidence worth preserving

- 기상청 단기예보는 3시간 간격으로 발표하며 모레까지(17시 이후 발표분은 글피까지) 제공합니다.
- 생활기상지수의 자외선지수는 3시간 간격으로 글피까지 예측하며 지점 단위로 조회합니다.
- 에어코리아 대기질 예보는 오늘, 내일, 모레의 PM10과 PM2.5를 시도 단위 4등급으로 주고, 모레 예보는 17시에 나옵니다.
- 자외선 지수는 `LivingWthrIdxServiceV5/getUVIdxV5`로 받습니다. 이전 안내에 있던 V4는 폐기되어 호출이 실패합니다. `time`을 당일 `00`시로 주면 h0이 0시, h3이 3시로 3시간 간격 값을 줍니다.
- 에어코리아 대기질 예보(`getMinuDustFrcstDspth`)는 발표 시각별로 여러 건을 주므로 같은 날짜에서 가장 늦은 발표를 써야 하고, 간헐적으로 5xx를 줍니다. 권역 이름은 서울, 경기북부, 경기남부, 영동, 영서, 광주, 전남 등으로 시도와 다릅니다.
- 기상청 단기예보는 발표 후 약 15분이 지나야 그 발표분을 받을 수 있습니다. 11시 발표분은 모레까지 시간별 기온(TMP), 풍속(WSD), 강수확률(POP)을 줍니다.
